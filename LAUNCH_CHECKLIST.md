# 🚀 Lemaiyan's Travels - Launch Checklist

This checklist will guide you through packaging your project and deploying it to your domain.

## 📦 Step 1: Package for GitHub

### ✅ Run the Git Setup Script

**For Windows:**
```cmd
setup-git.bat
```

**For Mac/Linux:**
```bash
chmod +x setup-git.sh
./setup-git.sh
```

### ✅ Manual Git Setup (Alternative)

```cmd
git init
git add .
git commit -m "Initial commit: Lemaiyan's Travels website"
```

## 🌐 Step 2: Create GitHub Repository

1. **Go to GitHub**: https://github.com/new
2. **Repository name**: `lemaiyans-travels`
3. **Description**: `Professional travel agency website built with Next.js`
4. **Visibility**: Public (or Private if you prefer)
5. **⚠️ Important**: Don't initialize with README, .gitignore, or license
6. **Click "Create repository"**

### ✅ Connect Local to GitHub

```cmd
git remote add origin https://github.com/YOUR_USERNAME/lemaiyans-travels.git
git branch -M main
git push -u origin main
```

## 🚀 Step 3: Deploy to Hosting

### Option A: Vercel (Recommended - Easiest)

1. **Sign up**: https://vercel.com (use GitHub account)
2. **Import Project**: Click "New Project" → Select `lemaiyans-travels`
3. **Configure**: Vercel auto-detects Next.js settings
4. **Deploy**: Click "Deploy" button
5. **Domain**: Go to Settings → Domains → Add your custom domain

### Option B: Netlify

1. **Sign up**: https://netlify.com
2. **Connect GitHub**: Import your repository
3. **Build Settings**:
   - Build command: `npm run build`
   - Publish directory: `.next`
4. **Deploy**: Automatic on push

### Option C: Traditional Hosting

1. **Build**: `npm run build`
2. **Upload**: Upload files to your hosting server
3. **Configure**: Set up Node.js environment
4. **Start**: `npm start`

## 🔧 Step 4: Domain Configuration

### DNS Settings for Vercel/Netlify

```
Type: CNAME
Name: @ (or your domain name)
Value: cname.vercel.com (or netlify DNS value)
TTL: 1 hour
```

### DNS Settings for Traditional Hosting

```
Type: A
Name: @
Value: YOUR_SERVER_IP

Type: A
Name: www
Value: YOUR_SERVER_IP
```

## 🆘 Troubleshooting

### Common Issues & Solutions

**Build Fails:**
```cmd
rm -rf .next
npm install
npm run build
```

**Domain Not Working:**
- Check DNS settings
- Wait 24-48 hours for propagation
- Verify SSL certificate

**Contact Form Not Working:**
- Check email configuration
- Verify server-side handling
- Test spam filters

**Images Not Loading:**
- Check file paths
- Verify image formats
- Optimize image sizes
